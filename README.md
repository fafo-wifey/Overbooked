# Overbooked v0.1: early functional prototype
Open index.html in a browser. This is a local-first HTML/JavaScript prototype, NOT an Android APK. Events, check-ins, cancellation reasons, favorite themes and palette selections persist in browser localStorage. No Google Calendar connection, background notifications, predictive ML model, recurring shift logic, app-icon switching, or production-ready calendar integration is implemented yet. Capacity currently uses a transparent illustrative workload heuristic (duration × demand, divided by 65 weekly units). For an Android APK, create an Android project, embed the web UI or migrate to native screens, configure Google OAuth and Calendar API scopes, and compile/sign using Android SDK/Gradle. Do not use as a sole scheduling system or for irreplaceable records.
